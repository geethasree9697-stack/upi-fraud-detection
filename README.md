# 💳 UPI Fraud Detection System

## 📌 Description

This project detects fraudulent UPI transactions using Machine Learning.

## 🧠 Tech Used

* Python
* XGBoost
* Flask

## 🚀 How to Run

1. Install libraries:
   pip install -r requirements.txt

2. Run:
   python app.py

3. Open:
   http://127.0.0.1:5000/
